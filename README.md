# 🚢 Análisis Exploratorio de Datos: Titanic

Este proyecto consiste en un Análisis Exploratorio de Datos (EDA) sobre el dataset del Titanic utilizando Python y librerías como pandas, seaborn y matplotlib. El objetivo fue identificar patrones relacionados con la supervivencia de los pasajeros.

---

## 📌 Objetivos

- Limpiar y preparar los datos
- Tratar valores nulos de forma estratégica
- Crear nuevas variables útiles (`age_group`)
- Visualizar patrones y relaciones
- Sacar conclusiones útiles basadas en los datos

---

## 🔧 Herramientas utilizadas

- Python 3
- Jupyter Notebook
- pandas
- seaborn
- matplotlib

---

## 📊 Análisis realizado

- Imputación de valores nulos en la edad con la media
- Eliminación de columnas con demasiados nulos
- Creación de grupos por edad (`Youth`, `Adult`, `Old`)
- Análisis de supervivencia por sexo, clase social y edad
- Visualización de datos mediante gráficos de barras y pastel

---

## 🧠 Conclusiones

- Las mujeres tuvieron una mayor tasa de supervivencia que los hombres.
- Los pasajeros de primera clase sobrevivieron en mayor proporción.
- Los más jóvenes también tuvieron más posibilidades de sobrevivir.
- Las decisiones de limpieza de datos ayudaron a mantener la integridad del análisis.

> Este proyecto sirve como base para futuros modelos predictivos y análisis más complejos.
